Repository documentation is the canonical written source for supported Agents++ behavior. The public documentation site indexes the guides in this directory without replacing their canonical source.

## Updating Documentation

A pull request must update the relevant guide when it changes a public API, supported workflow, security boundary, configuration requirement, migration, or operational procedure. Technical claims require review from the owner of the affected domain.
