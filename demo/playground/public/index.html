Known limitations
  • Local demo only. Authentication uses mock identities.
  • Demo views are not tenant-isolated production views.
  • Credential and signature data shown here is not independently verified by the browser.
  • Audit chain verification checks hash links, not signatures, completeness or deleted-record detection.
  • No LLM or external agent runtime is used by this Playground.
